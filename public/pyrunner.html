Common Errors
SyntaxError
Code isn't valid Python. Check for missing colons, brackets, or quotes.
IndentationError
Inconsistent spaces/tabs. Use 4 spaces per indent level consistently.
NameError
Variable used before being defined. Check spelling and order of code.
TypeError
Wrong type for an operation, e.g. adding a string to an int.
IndexError
Accessing a list index that doesn't exist. Lists start at index 0.
KeyError
Dictionary key doesn't exist. Use .get() for safe access.
ZeroDivisionError
Dividing by zero. Add a check before dividing.
AttributeError
Object doesn't have that method or property. Check the type.
ValueError
Right type but wrong value, e.g. int("abc") or math.sqrt(-1).
